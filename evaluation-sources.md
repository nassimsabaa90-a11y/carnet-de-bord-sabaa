# Évaluation de 3 sources (TD 3) – Nassim Sabaa

Grille appliquée : **QUI ? QUAND ? VRAI ? POURQUOI ? UTILE ?**

| Critère | Source 1 : Documentation Docker (`docs.docker.com`) | Source 2 : AWS Cloud (`aws.amazon.com`) | Source 3 : Stack Overflow Survey (`survey.stackoverflow.co`) |
| :--- | :--- | :--- | :--- |
| **QUI ?** | Équipe officielle de Docker Inc. (éditeur du logiciel). | Amazon Web Services (leader mondial du Cloud). | Stack Overflow (plus grande communauté de développeurs). |
| **QUAND ?** | Mise à jour continue selon les dernières versions de Docker. | Page maintenue à jour régulièrement (documentation de référence). | Enquête publiée chaque année (données récentes). |
| **VRAI ?** | Très fiable : source primaire officielle, commandes vérifiées. | Fiable techniquement sur les concepts, mais exemples orientés AWS. | Fiable : enquête basée sur des dizaines de milliers de répondants avec méthodologie publique. |
| **POURQUOI ?** | Expliquer aux utilisateurs comment installer et utiliser Docker. | Éduquer les débutants et promouvoir les services AWS. | Partager les tendances réelles de l'industrie logicielle. |
| **UTILE ?** | **Très utile** : indispensable pour la mise en pratique technique. | **Utile** pour la définition du Cloud et le vocabulaire en anglais. | **Complémentaire** : utile pour justifier le choix d'un outil populaire, mais pas un tutoriel. |

## Points de vigilance / Nuances (travail individuel)
- **Source 2 (AWS) :** Bien qu'elle soit claire et fiable pour comprendre le Cloud, il faut garder un esprit critique car AWS met en avant ses propres services payants (biais commercial). Il faudra comparer avec d'autres solutions gratuites comme GitHub Pages.
- **Source 3 (Enquête) :** Donne une vue globale, mais ne remplace pas la documentation technique officielle pour résoudre un problème concret.
