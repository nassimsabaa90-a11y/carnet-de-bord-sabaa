# Tableau de bord de veille – Nassim Sabaa

- **Question de veille :** Comment utiliser Docker et GitHub Pages pour tester puis héberger gratuitement un site web statique de manière fiable ?
- **Outils configurés :**
  1. GitHub `Watch → Custom → Releases` sur `docker/compose`
  2. Alerte Google hebdomadaire sur `"Docker release"` *(+ flux RSS `https://github.com/docker/compose/releases.atom`)*

## Mes 5 sources de veille

| # | Source (nom + adresse) | Type | Pourquoi cette source ? | Fréquence |
| :--- | :--- | :--- | :--- | :--- |
| **1** | **Documentation officielle Docker** (`https://docs.docker.com/`) | Documentation officielle | Référence fiable et officielle pour installer, configurer et utiliser les conteneurs. | Hebdomadaire |
| **2** | **Dépôt GitHub `docker/compose`** (`https://github.com/docker/compose`) | Dépôt GitHub | Suivre les nouvelles versions (*Releases*) et correctifs de Docker Compose. | À chaque sortie (*Watch*) |
| **3** | **AWS – What is Cloud Computing?** (`https://aws.amazon.com/what-is-cloud-computing/`) | Source en anglais | Comprendre les bases du Cloud (IaaS, PaaS, SaaS) et le vocabulaire technique en anglais. | Mensuelle |
| **4** | **Stack Overflow Developer Survey** (`https://survey.stackoverflow.co/`) | Rapport / Enquête | Analyser les statistiques réelles d'utilisation du Cloud, de GitHub et de Docker. | Annuelle |
| **5** | **The GitHub Blog** (`https://github.blog/`) | Blogue officiel | Suivre les nouveautés de GitHub, GitHub Pages et des bonnes pratiques de sécurité. | Hebdomadaire |
